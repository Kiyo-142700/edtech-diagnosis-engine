# EdTech Diagnosis Engine
Hệ thống chẩn đoán lỗ hổng kiến thức học tập.

## Mục tiêu dự án:
- Xây dựng engine phân tích kết quả học tập dựa trên đồ thị khái niệm.
- Tích hợp thang độ tự tin của sinh viên.
- Hỗ trợ sinh viên năm nhất củng cố kiến thức môn Toán và Lập trình.

## Công nghệ sử dụng:
- Java OOP, Spring Boot, MySQL.
- Git / GitHub, WSL2.
